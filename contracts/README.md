# Prompt Battle Arena

Prompt Battle Arena is a live multiplayer weekly mini-game built for GenLayer community gatherings.

Players connect with Discord, read the game rules, answer 10 GenLayer-focused questions within 5 minutes, and appear on a live leaderboard. Each correct answer gives 10 XP, while incorrect answers give 0. If players have the same score, the faster completion time ranks higher.

---

## Why GenLayer?

GenLayer focuses on Intelligent Contracts, AI-powered reasoning, and trustless adjudication.

This game demonstrates how GenLayer can support community experiences where outcomes are not only based on simple code, but also on fair judgment, AI-validator consensus, and transparent scoring.

---

## Game Features

- Discord login
- Live multiplayer room
- Welcome and rules page
- 10 weekly GenLayer questions
- 5-minute game timer
- 10 XP per correct answer
- 0 score for incorrect answers
- Final leaderboard
- Tie-break ranking by completion time
- Persistent leaderboard storage
- Admin-only reset endpoint

---

## Game Flow

1. Player connects with Discord
2. Player reads the GenLayer game rules
3. Player clicks PLAY
4. Player answers 10 questions
5. Final score is calculated
6. Leaderboard ranks players by score
7. If scores are tied, fastest time ranks higher

## GenLayer Concept

Prompt Battle Arena is designed to show how GenLayer can power fun, educational, and judgment-based games.

In the current MVP, the questions are objective quiz questions. In a full GenLayer version, Intelligent Contracts can evaluate natural-language answers, creative submissions, or subjective player responses using AI-validator consensus and Optimistic Democracy.
